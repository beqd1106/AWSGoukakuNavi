# 反復ドリル増量＋文字数の癖是正 — 作問仕様（v2）

AWS認定 Cloud Practitioner（CLF-C02）学習アプリ「AWSnote」の反復ドリル（同じ知識をランダム10問で繰り返し出題）を強化する。
あなたは担当ドメイン1つ分を仕上げ、`design/drills2/<domain>.js` を1ファイル書き出す。

## 出力ファイルの形

```js
const { q } = require("./_q");
const add = [];
const fix = [];

// --- add: 新規問題（q() を使う。正解は必ず先頭=index0。位置分散はハーネスが自動で行う） ---
add.push(
  q("qd-cc01-e1","cloudConcepts","クラウドとは",1,
    "質問文（末尾はどれですか。／正しいものはどれですか。等）",
    ["正解の選択肢","誤り1","誤り2","誤り3"],
    "なぜ正解かの解説（1〜2文）。",
    ["誤り1がなぜ違うか","誤り2がなぜ違うか","誤り3がなぜ違うか"],
    ["トピックタグ","任意でもう1つ"],   // "ドリル" は自動付与されるので書かない
    "初心者向けの一言ヒント"),
  // ...
);

// --- fix: 既存問題の選択肢だけ差し替えるパッチ（選択肢の順番は変えない！） ---
fix.push(
  { id: "qd-cc02-1", choices: ["…","…","…","…"] },
  // 必要なら誤答理由も更新可（キー "1"/"2"/"3" は既存の位置と対応）
  { id: "qd-cc05-5", choices: ["…","…","…","…"], wrongChoiceExplanations: {"1":"…","2":"…","3":"…"} },
);

module.exports = { add, fix };
```

## 最重要ルール：文字数の癖（tell）をなくす

現状、正解の選択肢だけが明らかに長い／詳しい問題が多く、内容を知らなくても「一番長いのが答え」で当ててしまえる。これを禁止する。

- **4つの選択肢は、文字数・具体度・語調をできるだけ揃える。** 目安：最長の選択肢が最短の1.3倍を超えない。
- 揃え方は「誤答を、もっともらしく具体的に肉付けする」を第一に。正解を不自然に削って意味が痩せるのは避ける。
- 誤答は "ありがちな誤解" として成立させる（明らかに変・投げやりな短文にしない）。
- 正解が先頭という位置の癖もハーネス側でローテーション分散するが、**あなたは常に正解を先頭に置く**（add）。

### 悪い例（正解だけ長い＝tell）
- 正解:「弾力性は需要に応じて自動で増減し、スケーラビリティは規模を拡大できる能力」
- 誤り:「同じ意味」「暗号化のこと」「セキュリティ機能」  ← 短すぎて丸わかり

### 良い例（4つとも同程度の具体度）
- 正解:「弾力性＝需要に応じて自動で増減する性質」
- 誤り:「スケーラビリティ＝規模を計画的に拡大できる能力」
- 誤り:「冗長性＝障害に備えて構成を多重化する考え方」
- 誤り:「移植性＝別環境へ移しやすくする設計」

## add（新規問題）の作り方

- 担当 `_ref_<domain>.json` の `need` を見て、各テーマを合計30問前後にする不足数だけ作る（`addNeeded` が目安）。
- 新IDは `qd-<テーマ>-e<n>`（例 `qd-cc01-e1`, `qd-cc01-e2` …）。テーマは `qd-cc01` 等、`-e1` から連番。既存の数字ID（-1,-2…）とは衝突しない。
- `_ref_<domain>.json` の既存 `question` と**内容が重複しないよう**言い換え・別角度で作る（用途→サービス／サービス→説明／シナリオ判断／穴埋め／誤り探し の5方向を混ぜる）。
- **CLF-C02の範囲を厳守**（SAA級の深掘り・細かい上限値やAPI詳細は出さない）。数値・事実は正確に。
- difficulty は 1（基本）中心、たまに 2。domain 値はドメイン固定（cc=cloudConcepts / sec=security / tec=technology / bil=billing）。
- `beginnerNote` は覚え方の一言（例「素早く調達＝俊敏性」）。空でもよいが付ける。
- 絵文字は使わない。日本語。

## fix（既存の癖是正）の作り方

- `_ref_<domain>.json` の各問題に `tell`（正解が単独最長）/`strong`（1.3倍以上）フラグと `correctIndex`・現在の `choices` がある。
- **`strong: true` は必ず是正**。`tell: true` も可能な限り是正。それ以外でも「正解だけ詳しい」と感じたら直す。
- パッチは `choices` を4つとも差し替え。**順番（indexの並び）は変えない**＝`correctIndex` の位置に正解が来るよう、既存と同じ並びで長さだけ揃える。
- 選択肢の言い回しを変えても、各誤答が表す「概念」は既存と同じに保てば、既存の `wrongChoiceExplanations` はそのまま有効（この場合 `wrongChoiceExplanations` は省略）。概念自体を変えたら `wrongChoiceExplanations` も一緒に更新する。
- 正解が引き続き唯一の正解であること、事実が正しいことを担保する。

## 完了条件
- `design/drills2/<domain>.js` が `module.exports = { add, fix }` で構文エラーなく `require` できる。
- add で各テーマ30問前後（既存＋add）。fix で strong を全消し。
- 出力後、自分で `node -e "require('./design/drills2/<domain>.js')"` 相当の読み込み確認をしてから終了報告する。
