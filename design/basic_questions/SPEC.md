# AWSnote「基礎問題」作成仕様（AWS Certified Cloud Practitioner CLF-C02 学習アプリ）

## 目的
各レッスンの確認問題の前に解く **「基礎問題」を各レッスン10問** 作る。
レッスン本文を一度読んだ初学者が **7〜9割解ける** 難易度にする。

## 難易度と中身（最重要）
- 問うのは、そのレッスンの柱となる **概念・サービス名・役割・用途**。1問1論点。
- **10問はすべて別々の論点にする**。同じ事実を言い回しだけ変えて何度も問わない（例：「リージョンとは」「東京などのまとまりを何と呼ぶ」「リージョンの説明として正しいもの」は同じ論点＝1問まで）。
- 論点はレッスン本文から取るのを基本とし、足りなければ **CLF-C02 の範囲で、そのレッスンのテーマに直結する基本事項** から取る。
- 設問は短く（60字以内目安）。「〜とは何か」「〜したいときに使うサービスはどれか」「〜の説明として正しいものはどれか」型を基本にする。
- 誤答は **明らかに別物だが無関係ではない** もの（同じ分野の別サービス・別の用語）。ひっかけ・部分的に正しい誤答・「〜のみ」「必ず」の揚げ足取りは使わない。
- 単一選択のみ（correctAnswers は要素1つ）。選択肢は必ず4つ。

## 事実の正確さ（必須）
- **料金・無料枠の量・SLAの%・サポートの応答時間・上限値・リージョン/AZの数などの数値を新しく書かない**。
  数値を使うのは、パケット内の「既存問題」かレッスン本文に既に出てくるものだけ。
- サービス名は正式名称（Amazon / AWS の付け方を含む）で書く。廃止・改名されたサービスを正解にしない。
- 自信のない事実は使わない。論点を差し替える。
- 各問に `basis`（根拠のメモ。「レッスン本文『〜』」または「AWS公式の〜の説明：…」を1文）を付ける。これは確認用でアプリには入らない。

## 選択肢の「長さの癖」を作らない（必須）
- 4つの選択肢の字数をそろえる（最長と最短の差は目安で10字以内）。**正解が一番長くならないよう**意識する。
- 正解位置は 0/1/2/3 をレッスン内で散らす（10問なら 3/3/2/2 程度）。
- 設問文に正解の語をそのまま含めない。

## 解説
- `explanation`：**「結論／それが何をするものか／混同しやすい隣との区別」の3点構成で100〜200字**。
- `wrongChoiceExplanations`：誤答3つそれぞれに、それが実際には何なのかを1文で（キーは "0"〜"3" の文字列、正解のキーは入れない）。
- `beginnerNote`：答えを書かずに着眼点を示す1文（ヒントとしてアプリに表示される。**正解の語を含めない**）。

## 既存問題との重複禁止
パケット末尾の既存問題と、設問＋正解が実質同じになる問題は作らない（同じ論点を、より基本的な別の角度から問うのはよい）。

## 出力形式
`out/<レッスンID>.json` に JSON 配列で書く。**3〜5問書くごとにファイルを上書き保存**すること（途中で止まっても成果が残るように）。

```json
{
  "id": "b-cc-01-01",
  "question": "…",
  "choices": ["…","…","…","…"],
  "correctAnswers": [2],
  "explanation": "…",
  "wrongChoiceExplanations": {"0":"…","1":"…","3":"…"},
  "domain": "cloudConcepts",
  "service": "<テーマ名。既存問題の [ ] 内の名前から最も近いものを使う>",
  "difficulty": 1,
  "tags": ["基礎", "<テーマ名>"],
  "beginnerNote": "…",
  "basis": "…"
}
```
- id は `b-<レッスンIDの l- を除いた部分>-01`〜`-10`（例：l-sec-03 → b-sec-03-01）。domain はパケット冒頭の domain。
- 書き終えたら、自分で次を検算して報告：正解が単独最長の問題数、正解位置の分布、解説の字数最小値、10問の論点が互いに別であること。

## 作業の進め方（必須・前回はこれを守らず全損した）
- 1レッスンにつき **Write を2回**：まず5問（-01〜-05）を書いて out/<レッスンID>.json を作成、次に10問全部で上書き。1回の出力を小さく保つ。
- 長い調査はしない（Web検索は不要）。レッスン資料と自分の確かな知識で書き、自信のない論点は使わない。
- 1レッスン書き終えたらすぐ次へ。検算は最後にまとめて短いスクリプトで行う。
