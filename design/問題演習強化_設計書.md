# AWS合格ナビ｜問題演習機能 強化 設計書

> 最新の試験範囲・配点・サービス内容・サポートプランは変更される可能性があります。**最新の試験情報は必ずAWS公式サイト（AWS Certified Cloud Practitioner 試験ガイド CLF-C02／各サービス公式ページ）でご確認ください。** 本アプリの問題・解説はすべてオリジナルで、公式問題・市販教材の転載はありません。

本書は既存アプリ「AWS合格ナビ（iOS版／オフラインWeb版）」を土台に、**問題演習（10問セット中心の反復学習）**を強化する設計をまとめたもの。いきなり実装せず、設計→サンプル問題→実装ステップの順で進める。

## 前提・置いた仮定（明記）
- **配点（CLF-C02）**：概念24% / セキュリティ30% / テクノロジー34% / 料金12%（既存アプリで公式確認済の数値を踏襲。最新は要再確認）。
- **データはローカルJSON（静的）でMVP**。クラウドDB・AI APIは必須にしない（コスト方針に従う）。
- **進捗保存**：iOS=SwiftData、Web=localStorage（既存実装を流用・拡張）。
- **AIは任意機能**（OFFでも全機能動作）。解説言い換え・類似問題生成は将来オプション。
- 既存の4分野・忘却曲線復習・模試・合格可能性スコア・バッジは**作り直さず拡張**する。
- 問題総数は段階的に増やす（MVPは現行98問＋本書サンプル40問をベースに拡充）。

## 1. 問題演習機能の全体方針
- **講義より演習**。「10問解く→即採点→丁寧な解説→間違いを復習」のループを最短導線にする。
- **10問セット**を学習の最小単位にし、1セットごとに達成感（クリア判定・バッジ・正答率）を出す。
- **分野別に大量のセット**を用意し、初心者向け（Beginner〜Basic）と本番形式（Exam-like）を分離。
- **苦手の可視化**（分野別正答率・苦手タグ）→ おすすめセットへ誘導。
- 十分な演習量に達したら**本番形式65問模試**へ接続。
- すべて**オフライン完結・低コスト**。AIは後付け可能なオプション層として分離。

## 2. 分野別の問題数設計（目標）
| 分野 | 目標問題数 | 10問セット数の目安 |
|---|---|---|
| Cloud Concepts | 100問以上 | 10セット＋総復習 |
| Security and Compliance | 150問以上 | 15セット＋総復習 |
| Cloud Technology and Services | 200問以上 | 20セット＋総復習 |
| Billing, Pricing, and Support | 80問以上 | 8セット＋総復習 |
| 総合模擬試験 | 65問×3回分以上 | 模試プール（配点比率で動的生成も可） |
| **合計** | **最低500問以上** | — |

MVP段階：各分野の代表セット（本書サンプル各10問）から開始し、セット追加で総数を伸ばす。データ追加だけで増やせる構造にする（コード改修不要）。

## 3. 10問セットの構成案
- 1セット＝**10問固定**。難易度は混在可だが「初心者向けセット」と「本番形式セット」は分ける。
- **クリア条件＝8問正解（80%）以上**（合格ライン表示）。満点で特別演出。
- 各セットに表示：**セット名／分野／難易度／問題数／推定時間／達成率／正答率／完了バッジ／復習対象数**。
- 推定時間＝問題数 × 約45〜50秒（10問で約8分）。本番形式は1問あたり長めに見積もる。

例：
```
IAM基礎セット（10問） ─ Security ─ 難易度: Basic
推定時間: 8分 ／ 合格ライン: 8問正解
達成率: 60%（6/10解答済）／ 正答率: 67%
クリアで「IAMマスター」バッジ獲得 ／ 復習対象: 2問
```

## 4. 分野別セット一覧（案）
**Cloud Concepts**：①クラウド基礎 ②クラウドメリット ③弾力性・俊敏性 ④Well-Architected ⑤CAF ⑥グローバルインフラ ⑦高可用性 ⑧オンプレ比較(CAPEX/OPEX) ⑨移行の価値 ⑩総復習
**Security and Compliance**：①責任共有モデル ②IAM基礎 ③IAM応用(ロール/ポリシー) ④認証・MFA ⑤セキュリティサービス(KMS/Shield/WAF/GuardDuty) ⑥データ保護・暗号化 ⑦コンプライアンス(Artifact) ⑧ガバナンス(Organizations/SCP) ⑨アカウント保護 ⑩〜⑮応用＋総復習
**Cloud Technology and Services**：①コンピューティング ②ストレージ ③データベース ④ネットワーク ⑤配信(CloudFront/Route 53) ⑥監視・運用(CloudWatch/CloudTrail) ⑦自動化・IaC ⑧コンテナ/サーバーレス ⑨AI/ML ⑩分析 ⑪移行 ⑫〜⑳応用＋総復習
**Billing, Pricing, and Support**：①料金モデル ②EC2購入オプション ③コスト最適化(Savings Plans) ④コスト管理ツール(Budgets/Cost Explorer) ⑤見積(Pricing Calculator) ⑥サポートプラン ⑦請求管理(Organizations一括請求) ⑧無料利用枠＋総復習

## 5. 問題データ構造（QuizQuestion v2）
既存スキーマを後方互換で拡張（新フィールドは任意：未設定でも既存UIは動く）。
```jsonc
{
  "id": "sec-iam-001",
  "domain": "security",            // cloudConcepts|security|technology|billing
  "category": "IAM",               // 分野内のテーマ
  "setName": "IAM基礎セット",       // 所属する10問セット
  "difficulty": "Basic",           // Beginner|Basic|Standard|Exam-like
  "questionType": "single",        // single|multiple|term|service-select|usecase|
                                   //  shared-responsibility|billing-support|comparison
  "question": "…",
  "choices": ["…","…","…","…"],
  "correctAnswers": [0],           // 0始まりindex配列（複数選択対応）
  "explanation": "なぜ正解か…",
  "wrongChoiceExplanations": { "1": "…", "2": "…" },
  "examPoint": "試験で狙われるポイント",
  "beginnerTip": "初心者向けの覚え方のコツ",
  "relatedServices": ["AWS IAM"],
  "tags": ["IAM","最小権限"],
  "factCheckSource": "AWS IAM ベストプラクティス公式",   // 検証先
  "createdAt": "2026-06-24",
  "updatedAt": "2026-06-24"
}
```
- 既存 `beginnerNote` → `beginnerTip` に統一（移行時マッピング）。既存問題はスクリプトで `category/setName/difficulty/questionType` を補完。
- セット定義は別ファイル `quiz_sets.json`（id, name, domain, difficulty, questionIds[], passLine, badgeId, estimatedMinutes）で管理し、問題との多対一を表現。

## 6. 画面構成
- **演習ハブ**：今日の10問 ／ 分野タブ ／ 各分野のセット一覧（進捗バッジ付き） ／ 復習 ／ 模試。
- **セット一覧（分野別）**：セットカード（名前・難易度・推定時間・達成率・正答率・クリア有無・復習対象数）。
- **問題プレイヤー（10問）**：問題番号・残数・進捗バー・選択肢カード・回答・「あとで見直す」フラグ・一時保存。
- **セット結果画面**：スコアリング（◯/10・正答率）・クリア/未クリア・前回比・全問の解説（誤答を強調）・「復習に追加」「再挑戦」。
- **復習画面**：期限到来の問題・間違えた理由・正しい考え方・「理解済み」「あとでもう一度」。
- **分野ダッシュボード**：総問題数/解答済/正答率/苦手タグ/未クリア・クリア済セット/復習待ち/模試での分野別スコア。
- **模試**：開始→65問（フィードバックなし・タイマー）→結果（分野別・次に解くセット提案）。
- **デザイン**：白・ネイビー・ブルー・AWSオレンジ・淡グレー（既存Themeを踏襲）。スマホ/PC両対応。

## 7. 学習フロー
1. **今日の10問**（ホームから即開始）→ 2. **分野別10問セット選択** → 3. **即採点（10問終了時）** → 4. **全問解説（誤答強調）** → 5. **復習自動登録（誤答・迷った問題）** → 6. **再チャレンジ（前回超えで演出）** → 7. 十分な演習量で**65問模試**へ。

## 8. 復習アルゴリズム（忘却曲線）
- 既存の SpacedRepetition を流用：**間隔 1日→3日→7日→14日→30日**。正解で段階アップ、誤答で段階0に戻し翌日再出題。最終段階クリアで「卒業（リストから除外）」。
- 復習タイミング：**当日／翌日／3日後／7日後／試験直前**（試験直前モードは苦手＋誤答を優先出題）。
- 「迷った問題」フラグ（あとで見直す）も復習候補に追加。「理解済み」で即時卒業、「あとでもう一度」で翌日へ再設定。
- 復習画面は「間違えた問題・理由・正しい考え方・再出題」をワンセットで提示。

## 9. 達成感を出すUI演出
- 10問終了時の**クリア表示**（80%以上でクリア、満点で特別演出＝紙吹雪/スタンプ）。
- **バッジ**：分野別マスター／苦手克服／模試合格／分野制覇（全セットクリア）／復習完了／連続学習。
- 数値の見える化：**今日の達成数・今週解いた数・累計解答数・連続学習日数・分野別達成率**。
- 再挑戦で**前回スコア超え演出**。セット一覧に**クリア済みチェック**でコレクション感を出す。
- アニメは意味のある所だけ 0.15〜0.35s（既存のデザイン品質ルール準拠）。

## 10. 模擬試験設計
- **本番形式65問／想定90分**。分野比率は公式配点（24/30/34/12%）に合わせて動的抽選（既存 buildMockExam を流用）。
- 途中フィードバックなし・タイマー表示。終了で**スケールスコア（100〜1000・合格目安700）**換算。
- 結果：総合スコア／合格ライン到達目安／分野別正答率／間違えた問題一覧／復習すべきセット／**次に解くべき10問セット提案**／試験直前アドバイス。
- 模試3回分以上はプール式（重複を避けて出題）で実現。

## 11. 合格可能性スコア設計（目安・保証しない）
既存 PassProbability を拡張。要素と重みの案：
- 分野別正答率（公式配点で加重）… 40%
- 直近の模試スケールスコア（700基準）… 20%
- 直近7日間の学習量 … 10%
- 復習完了率 … 10%
- 10問セットのクリア数（網羅度）… 10%
- 苦手分野の残り数（少ないほど加点）… 10%

表示例：「合格可能性 目安74% ／ Cloud Technology and Services の正答率が低めです。ストレージ・データベース・ネットワークの10問セットを復習しましょう。」
**必ず『学習の目安であり合否を保証・予測しない』旨を併記。**

## 12. ファクトチェック方針
- 確認先：**AWS公式ドキュメント／CLF-C02 試験ガイド／AWS Skill Builder／各サービス公式ページ**。
- 特に最新性に注意：サービス名・料金・サポートプラン・責任共有モデル・セキュリティサービス・Well-Architected・CAF・試験範囲・出題比率。
- 各問題に `factCheckSource` を持たせ、検証先を明記。断定できない項目は「公式情報で要確認」と明記。
- AI生成の問題・解説は**公開前に必ず人手＋公式照合**。公式問題・教材のコピーは禁止。グローバル `/factcheck` スキルで数値・制度を定期照合。

## 13. コスト管理方針
- MVPは**ローカルJSON＋静的配信**で月額ほぼ0円（Web=Cloudflare/ローカル、iOS=端末内）。
- AI APIを使う場合のみ：**利用回数制限・結果キャッシュ・月額上限・コスト警告**を必須実装。OFFでも全機能動作。
- ユーザーの全アプリ合計**月額20,000円以内**を厳守。クラウドDB/AIは必要時のみ・無理に使わない。

## 14. サンプル問題（各分野10問＝合計40問）
別ファイル **`design/questions_v2_sample.json`** に40問（新スキーマ準拠）を収録。
- 内訳：Cloud Concepts 10／Security 10／Technology 10／Billing 10。
- 各問に「正解理由・不正解理由・初心者補足(beginnerTip)・試験ポイント(examPoint)・関連サービス・ファクトチェック先(factCheckSource)」を付与。
- 代表例は本書末尾および回答メッセージ参照。すべてオリジナル・公式範囲準拠。**内容は公開前に最新の公式情報で要再確認**（特に料金・サポートプラン）。

## 15. 実装ステップ
1. **データ移行**：既存98問に `category/setName/difficulty/questionType/examPoint/beginnerTip/factCheckSource` を補完。`beginnerNote`→`beginnerTip`。
2. **セット定義**：`quiz_sets.json` を作成（分野×テーマで10問束ね・passLine=8・badgeId）。
3. **モデル拡張**：QuizQuestion v2＋QuizSet＋SetProgress（クリア状態・最高スコア・最終挑戦日）。
4. **演習ハブ／セット一覧UI**：分野タブ＋セットカード（達成率・正答率・クリア・復習対象数）。
5. **10問プレイヤー**：既存QuizPlayerを「10問固定・最後に一括採点モード」も選べるよう拡張（即時採点モードと両立）。
6. **セット結果画面**：クリア判定・前回比・誤答強調・復習追加・再挑戦・満点演出。
7. **復習強化**：「あとで見直す」フラグ・理解済み/あとでもう一度・試験直前優先。
8. **分野ダッシュボード**：苦手タグ算出（正答率×タグ集計）＋おすすめセット誘導。
9. **模試拡張**：結果に「次に解くべきセット」提案を追加。
10. **合格可能性スコア v2**：重み更新＋根拠コメント生成。
11. **問題増殖**：各分野を目標数まで追加（データのみ）。`/factcheck` で照合。
12. **（任意）AI層**：解説言い換え・類似問題生成・苦手別プラン。回数/上限/キャッシュ/警告つき。
13. **Web⇄iOS 同期**：同一 `*.json` を単一ソースにし、Web(data.js生成)・iOS(Resources)へ反映（用語集glossary.jsonと同方式）。
